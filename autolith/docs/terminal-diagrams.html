Terminal diagrams

Ask for a fenced mermaid block to see a diagram in the terminal. Clermaid documents the supported syntax for:

  • Flowcharts
  • Sequence diagrams
  • Flat state diagrams
  • Class diagrams
  • Entity relationship diagrams
markdown 
```mermaid
flowchart LR
  A[Read] --> B[Evaluate]
  B --> C[Print]
```

While the response streams, read the Mermaid source in the live tail. Use the copy action on the finished diagram to copy the source. If the syntax is unsupported or the diagram is too wide, read the source block instead.
