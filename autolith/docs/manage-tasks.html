Manage delegated tasks and jobs

Delegate a task

Ask Autolith to delegate work if you want a second pass on a change while you work on something else. For example, try Have another agent review this diff and report any regressions. Do not edit files..

Include the files to review and what you want back. If you want to follow the work directly, open the child channel from the sidebar.

Recover an interrupted job

Ask Autolith to check which parts of the job finished. Review any files or other changes the job produced before you ask Autolith to resume or retry it.

Keep delegated edits in a separate checkout

If you and another agent need to edit the same project, ask Autolith to delegate the changes in a separate Git worktree. Ask for the patch when the job finishes. Review it before you apply it to your checkout.
