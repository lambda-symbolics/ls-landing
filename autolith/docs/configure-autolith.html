Configure Autolith

Change a setting

  1. Run (settings) to open the settings picker.
  2. Select a setting to see the current value, where it was set and the available choices.
  3. Choose a value. Autolith saves durable settings in preferences.sexp. Session settings last until you exit.

At the prompt, (settings :boot-screen-seconds) shows the setting and (settings :boot-screen-seconds 2) changes it. Pass nil explicitly to turn off a switch.

For durable settings, Autolith checks these sources in order and uses the first value it finds:

  1. A command-line option.
  2. The environment variable for the setting.
  3. The saved preference.

Find your configuration files

Put personal configuration in ${XDG_CONFIG_HOME:-~/.config}/autolith/init.lisp. Autolith evaluates the file in the AUTOLITH package with your privileges. Start with --pristine to skip executable initialization and private replay.

Autolith loads configuration in this order:

  1. The site init.lisp, if you set a site root with --site-config-root DIRECTORY or AUTOLITH_SITE_CONFIG_ROOT. Use an existing absolute directory.
  2. Trusted .autolith/init.lisp files, from the outermost directory to the nearest one.
  3. Your personal init.lisp.
