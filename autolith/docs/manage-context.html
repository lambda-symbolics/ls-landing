Manage context

Compact a long conversation

Autolith compacts long conversations into a checkpoint and keeps recent turns. The context meter shows the token count. The | marks the automatic compaction point.

  • Run (compact) to make a checkpoint now. If a turn is active, Autolith waits until the turn ends.
  • Use (settings :compaction-threshold-percent) to inspect the threshold. The default is 80% of the context window.
  • Read the transcript if you need the exact text of earlier messages or tool results.

Add guidance for a project

Context rules add instructions to model requests that match conditions you specify. Run (context) to see the guidance in use.

Save a correction

  1. Run (complain "Your explanations are too long. Give the result first.").
  2. Review the suggested instruction and the text that triggers it. Edit either one if needed.
  3. Save it for the current workspace or for all workspaces.

Write a rule in Lisp

Put this example in init.lisp to add a reminder after successful tools run on Common Lisp files under src/:

Common Lisp 
(register-context-rule
 '(:id "lisp-edits"
   :when (:paths ("src/") :languages ("common-lisp")
          :events ("tool-success"))
   :instruction "Check the changed declarations before committing."
   :priority 30 :lifetime :while-relevant))

Add an absolute :workspace directory to restrict the rule to one project. Use context-status to check whether the rule was used and unregister-context-rule with the rule ID to remove it.

Set token limits

Inspect the effective limits with (status). Use (settings) to find settings for the active model.

  • Context window. Set AUTOLITH_CONTEXT_WINDOW for one launch if you need to override the window.
  • Reply length. Set (settings :max-output-tokens N) to cap the tokens requested for one reply. Use nil to clear the override.
