Customise commands, skills and Lisp

Write a command

Define commands in init.lisp with define-application-command. This example adds (my-version) and accepts an optional label:

Common Lisp 
(define-application-command my-version-command
    (:name              "my-version"
     :aliases           ("local-version")
     :argument          "[LABEL]"
     :description       "show a labeled local integration version"
     :tip               "shows the version supplied by init.lisp."
     :busy-behavior     :execute
     :terminal-behavior :shared
     :callable          t)
    (application &optional (label "integration"))
  (application-present application (format nil "~A 3" label))
  :continue)

After restarting, run (help 'my-version) to check the help for the command.

Load a skill

Ask Autolith to load a skill by name, or use skill.load with the exact name. Read skill:NAME with resource.read to see the catalog entry.

Change a live definition

  1. Use self.define to add or replace a definition in the running image. Qualify the symbol if it belongs to another package.
  2. Test the change in the active image and review it with self.diff.
  3. Save the change with self.commit or undo it with self.discard.

If an update skips an override because the tracked definition changed, run (fix-skipped-definitions) to review and rebuild the overrides you still need. See Generations and recovery for restore commands.

Redact text locally

Use (redact text) at the Lisp prompt or autolith:redact in a worker. Check the second return value for :ok. Review the redacted text before sharing it.

Connect to the running Lisp image

  1. Put a nonempty token in ${XDG_CONFIG_HOME:-~/.config}/autolith/management-repl.token. Own the file and set the permissions to 0600.
  2. Connect from a trusted local Lisp client with eval-connect from image-daemon. On Unix, the default socket is ${XDG_STATE_HOME:-~/.local/state}/autolith/management/repl.sock. On Windows, use 127.0.0.1:4141.
  3. Use eval-call to evaluate a form in the running image. Review the result before sharing it because it may contain secrets.
