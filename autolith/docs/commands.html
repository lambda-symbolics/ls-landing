Slash commands

Every interactive command is one / away. Aliases are shown in the second column; /help always shows the current reference, and the terminal completes commands and their options as you type.

CommandAliasesWhat it does
/helpshow this reference
/newstart a new conversation
/resumepick a saved conversation to resume
/conversationslist saved conversations
/historyload earlier transcript history
/cwdshow or change the active workspace
/authpick and authenticate a registered provider
/modelpick a registered provider model and reasoning effort
/modelslist registered providers and models
/effortpick the reasoning effort
/fastshow or change Codex Fast mode
/traceshow visible reasoning summaries
/timestampsshow local timestamps beside user and assistant turns
/steuse Simple Technical English for replies
/titlesallow provider-generated session-title refreshes
/hurry-upshow or change hurry-up mode
/permissionschoose command access for this session
/goalset or view the session goal
/agendashow workspace agenda entries
/papercutsshow workspace papercut reports
/papercutshow one complete papercut report
/papercut-closeclose one resolved papercut report
/skillsshow available skills
/mcpshow or refresh configured MCP servers
/checkpointsave a retained live generation
/generationslist retained generations
/rollbackpick a generation for recovery
/infoshow current model and runtime settings
/status/usageshow usage and rate limits
/updatecheck and install a newer packaged release
/contextinspect request-local context
/compactcondense tool details, or summarize context with no argument
/detachdetach Autolith from the current terminal
/quit/exitleave Autolith
/vaultinspect recovered queued input
/vault-restorerestore recovered queued input
/vault-discarddiscard recovered queued input
