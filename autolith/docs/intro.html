Docs · Intro

Development guide. For Autolith 0.67.66, see the release guide.

Intro

  1. Install Autolith. Choose a command in Install, update, and uninstall.
  2. Sign in to a model provider. For example, run autolith auth chatgpt and follow the prompts. If you use nix run, run nix run github:lambda-symbolics/autolith -- auth chatgpt instead.
  3. Open a channel. Run autolith or nix run github:lambda-symbolics/autolith in the directory where you want to work. In fullscreen mode, select inbox or another channel in the sidebar. Use autolith open for the most recently used top-level channel in the workspace, or autolith open ID for a specific channel.
  4. Send your first request. Try List the files in this workspace and tell me where to start. To see commands, enter (help) in the same prompt.

Write requests in plain text and enter Lisp commands as parenthesized forms. For example, you can inspect the workspace directly:

Common Lisp 
(resource.read :uri "workspace:.")
  • Type an opening parenthesis, bracket, or brace to insert a pair. Type the closing delimiter to move past it, or press Backspace inside an empty pair to delete both delimiters.
  • Press Tab to complete a command, option, path, or @ mention. If you complete a mention, press Tab again to cycle through candidates. Use Shift-Tab to cycle backward.
  • If there is nothing to complete, Tab submits the prompt or queues it during a turn. Finish an open Lisp form before submitting it.
