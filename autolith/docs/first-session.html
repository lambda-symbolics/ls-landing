Docs · First session

First session

  1. Connect a model provider. To use ChatGPT, run autolith auth chatgpt and follow the prompts. If you use nix run, run nix run github:lambda-symbolics/autolith -- auth chatgpt instead. You can also run a local model with Ollama.
  2. Open a channel. Run autolith or nix run github:lambda-symbolics/autolith in the directory where you want to work. Select inbox or another channel in the sidebar. Use autolith open to reopen the most recent top-level channel in the workspace, or autolith open ID to open a specific channel.
  3. Send your first request. Try List the files in this workspace and tell me where to start. To see commands, enter (help) in the same prompt.

Write requests in plain text and enter Lisp commands as parenthesized forms. For example, you can inspect the workspace directly:

Common Lisp 
(resource.read :uri "workspace:.")
  • Type an opening parenthesis, bracket, or brace to insert a pair. Type the closing delimiter to move past it, or press Backspace inside an empty pair to delete both delimiters.
  • Press Tab to complete a command, option, path, or @ mention. If you complete a mention, press Tab again to cycle through candidates. Use Shift-Tab to cycle backward.
  • If there is nothing to complete, Tab submits the prompt or queues it during a turn. Finish an open Lisp form before submitting it.

Onboarding

  1. Open a channel. At the boot screen, press Space or Enter to start the tour. To go straight to the prompt, press Esc or start typing. Typed and pasted text is kept in the prompt.
  2. Try the exercises on the prompt, (help), background Lisp, and (settings). Edit the exercise input and press Enter to submit it.
  • Use Page Up and Page Down to scroll.
  • Press Shift-Tab to go back or Tab to skip one slide, including an exercise.
  • Press Esc to skip the tour. Press Ctrl-C to interrupt it without marking unfinished lessons as skipped.

On later launches, you see only new or revised lessons. Enter (onboard) to replay the full tour. To disable the automatic tour, enter (settings :onboarding-p nil) or set AUTOLITH_ONBOARDING to off. If you disable the boot screen, you skip the opening animation.

Boot screen

  • To skip the wait, use (setf (config :boot-screen-linger-p) nil) or set AUTOLITH_BOOT_LINGER to off for one launch.
  • To change the direct-session animation from 3.5 seconds, set :boot-screen-seconds or AUTOLITH_BOOT_DURATION. A hosted channel shows actual progress and does not replay the animation.
  • To skip the boot screen, use (setf (config :boot-screen-p) nil) or set AUTOLITH_BOOT_SCREEN to off. See (settings) for these options.
