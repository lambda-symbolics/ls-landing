Common Lisp libraries

A registry of packages developed by Lambda Symbolics OÜ with contributions from friends and associates. These libraries are open-source, actively maintained, and suitable for general-purpose use within their domains.

AI and agents

agentcomms

lambda-symbolics/agentcomms

Agent Client Protocol v1 over newline-delimited JSON-RPC. Includes request correlation, cancellation, capability negotiation, and standard-I/O or in-process channels.

cl-llm-provider-api

lambda-symbolics/cl-llm-provider-api

Protocols, value types, and wire clients for language-model providers. Includes context assembly, structured-output contracts, inference budgets, and content-addressed contexts.

cl-skills

lambda-symbolics/cl-skills

Discovery, validation, and reading of reusable Agent Skills. Supports SKILL.md directories and a bounded native SKILL.sexp format.

clinker-transcript

lambda-symbolics/clinker-transcript

Typed provider transcripts for Responses and Chat Completions, with constructors, canonicalization, compaction checkpoints, and records for server-executed calls.

mcparen

lambda-symbolics/mcparen

A reasonably comprehensive Model Context Protocol client implemented in Common Lisp.

Terminal and desktop interfaces

cl-colorist

lambda-symbolics/cl-colorist

Dependency-free ANSI text styling which automatically detects terminal capability and gracefully degrades graphics.

cl-termdown

lambda-symbolics/cl-termdown

Parses Markdown into terminal-oriented semantic spans, with Unicode-aware wrapping, lists, inline markup, tables, fenced code, and streaming previews.

clinedi

lambda-symbolics/clinedi

Portable, Unicode-aware terminal line editor: grapheme-cluster movement, completion, highlighting, persistent history, and inline suggestions.

colordiff

lambda-symbolics/colordiff

Colorful, syntax-highlighted endpoint diffs for terminals. Compares whole documents and renders one bounded change block.

colorlisp

lambda-symbolics/colorlisp

Style-neutral syntax highlighting for Common Lisp applications. One native library across many languages; the host supplies colors, the library supplies spans.

lightfast

lambda-symbolics/lightfast

Small, direct Common Lisp bindings for FLTK 1.4, plus a deterministic flex-style layout engine for nested rows and columns. Adds optional layout calculation separate from widgets.

sophisticated-clipboard

lambda-symbolics/sophisticated-clipboard

Desktop clipboard access for Common Lisp, including text and typed data. Uses platform interfaces without requiring compiled glue code.

Source and document tools

cl-hashline

lambda-symbolics/cl-hashline

Line-anchored text editing against an observed revision. Validates anchors and applies batches of edits in original-line coordinates.

cl-lsp

lambda-symbolics/cl-lsp

Client for standard-I/O Language Server Protocol servers. Includes initialization, UTF-8 file synchronization, JSON-RPC requests, and push or pull diagnostics.

clifff

lambda-symbolics/clifff

Bindings and a supervised worker for the fff search library. The supervised worker can be automatically restarted in case of (rare) fff failure.

lambda-debugger

lambda-symbolics/lambda-debugger

Live Common Lisp restart debugger with portable snapshots. Supports restart selection, source-backed repair, retrying operations, returning values, and aborting.

org-templater

lambda-symbolics/org-templater

Org document templating with key interpolation and conditional blocks. Heading properties can control whether a subtree is included.

parenchek

lambda-symbolics/parenchek

Missing and mismatched delimiter checker for Common Lisp, Scheme, and Clojure. Reports unexpected closers and unclosed openers with line and column.

surgeon

lambda-symbolics/surgeon

SBCL introspection and reversible live redefinition. Includes defined-name lookup, lambda lists, restart selection, definition undo, and source-form location.

Processes and images

cl-exec-sandbox

lambda-symbolics/cl-exec-sandbox

Policy-driven sandboxing for external processes. Policies control what children can read, write, and reach.

cl-jobpond

lambda-symbolics/cl-jobpond

Bounded thread pool for supervised jobs. Cancellation, deadlines, progress, and exactly one terminal result per job.

image-daemon

lambda-symbolics/image-daemon

Wire and runtime protocols for Lisp image daemons, with authenticated loopback control, bounded packets, request deadlines, session identifiers, and terminal relays.

ls-flock

lambda-symbolics/ls-flock

Advisory POSIX file locks through lockf. Includes scoped locking and process-wide mutex serialization for threads locking the same path.

sbcl-generations

lambda-symbolics/sbcl-generations

Checkpoint a live SBCL image without stopping it. Numbered generations are boot-probed before publication; select which one boots next.

sbcl-workers

lambda-symbolics/sbcl-workers

Persistent, isolated SBCL worker processes and immutable heap images. Long-lived helpers that outlive individual work and can be restored from a known-good image.

Data and configuration

argo

lambda-symbolics/argo

RFC 8259 JSON encoding and decoding with distinct false, null, and empty-array values. Optional limits bound document processing.

idsmall

lambda-symbolics/idsmall

Short, human-typable identifiers with a reversibly scrambled timestamp. Seven Base58 characters; easy to read aloud and type.

setinka

lambda-symbolics/setinka

Layered, typed configuration through documented CLOS settings. Includes source precedence, persistence, change listeners, and updates to dependent settings.

sexp-config

lambda-symbolics/sexp-config

Read s-expression configuration without evaluation. A grammar declares the allowed vocabulary and bounds; anything outside is refused.

sexp-store

lambda-symbolics/sexp-store

Crash-tolerant state files stored as readable s-expressions. Useful to create s-expression ledgers of actions taken by, say, a clanker.

structlisp

lambda-symbolics/structlisp

Portable data structures using ANSI Common Lisp: deques, bounded sequence builders, heaps, ordered maps, caches, string indexes, and integer interval collections.

Web and authentication

cl-rfc8252

lambda-symbolics/cl-rfc8252

Browser-based OAuth for installed applications, with S256 PKCE, IPv4 loopback redirects, and authorization-code exchange. Integrates with cl-rfc8628 credential storage.

cl-rfc8628

lambda-symbolics/cl-rfc8628

OAuth 2.0 device authorization through a CLOS protocol, with replaceable HTTP, clock, browser, and sleep operations, plus credential storage.

fetch-gist

lambda-symbolics/fetch-gist

Fetches web pages over HTTP and converts HTML to Markdown. Uses Dexador for requests and Plump for HTML parsing.

lispolar

lambda-symbolics/lispolar

A Common Lisp client for Polar.sh: checkout sessions, checkout-link URLs, customer portal sessions, and Standard Webhooks signature verification.

Portability and licensing

COLL

luciusmagn/COLL

A configurable license family whose operative terms are in Common Lisp. Select terms to produce variants ranging from FOSS to proprietary.

ls-compat

lambda-symbolics/ls-compat

A portability facade for Common Lisp applications to make projects portable across SBCL, CCL, and usually ECL. Honestly a mixed bag, a number of La-Sy libs depend on it
